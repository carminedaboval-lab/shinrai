# Midori Park game-ready structures

These files are exact working copies of the approved source GLBs. The untouched collection sources remain under `source_glb/`.

- `midori_main_arched_bridge_v1.glb` — WAT-01, placed as the principal south-lake crossing.
- `midori_secondary_footbridge_v1.glb` — WAT-02, placed as the flatter north-lobe route.
- `midori_lakeside_viewing_deck_v1.glb` — WAT-03, placed on the eastern lake edge with a planned loot socket.

The current scene supplies simple gameplay collision separately. Mesh cleanup and final authored collision remain scheduled for the detailed asset pass.

Both bridge lengths are provisional. Their final spans will be adjusted after the shoreline and promenade widths are approved.
