# Shinrai Japan 2050 signage

Original vector seal geometries created for Mori Coffee, Ueda Books, Hinata Daily, Yakitori Shop, and Haku Ceramics. English shop names retained. Japanese brand names: 森珈琲 / 上田書店 / ひなた商店 / 焼鳥 / ハク陶器.

All SVG lettering is path geometry derived from Noto Sans JP and Noto Serif JP, licensed under SIL Open Font License 1.1. Unmodified license notices and source provenance are included. No runtime font dependency; TTF sources are kept only in staging/fonts.

Seals were drawn from original coordinates in build_logos.py, not stock icons or AI-generated raster images. Fascias are transparent and tightly cropped to individual content bounds (dimensions and actual ratios in manifest.json); marks are transparent 1000×1000. Revision 02 recomposes only fascias for installed readability: English is 137 px in side-by-side two-line street lockups and 98 px in the stacked Haku lockup. Glyphs retain uniform scale. All five mark hashes remain unchanged, recorded in staging/mark_hashes_unchanged.json. Palette and conservative visible bounds are in manifest.json. Glyph cmap coverage verified during generation, SVGs contain no text elements, links, scripts, embedded raster images, or external resources.

This is a staging candidate. Runtime installation, legibility at player height, and visual acceptance belong to the integration owner.
