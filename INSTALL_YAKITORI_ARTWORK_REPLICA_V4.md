# SHINRAI Yakitori Shop V4 — Drop-in installation

1. Close Godot.
2. Extract this ZIP into the repository folder containing `project.godot`.
3. Allow it to replace `scripts/town_main.gd`.
4. Reopen Godot and run `res://scenes/main.tscn`.

The game will automatically instantiate:

`res://assets/shinrai/buildings/yakitori_shop/artwork_replica_v4/ProjectShinrai_YakitoriShop_ArtworkReplica_v4.tscn`

For isolated inspection, double-click that scene, switch to the 3D workspace,
select the Model, press `F`, then use `Shift+F`, `WASD`, `E`, and `Q`.

V4 corrects the side-wall joints, plaster/stone colors, blue metallic roof,
roof guard scale, eave weight, timber grain direction, and canopy-light emission.
Signage, lanterns/noren, final glass, and interior design remain deferred.
