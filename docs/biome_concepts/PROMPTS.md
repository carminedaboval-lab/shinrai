# Biome concept prompts (image-to-image)

Each "after" is generated from the matching in-game screenshot `now_<area>.png` as the reference image, keeping the same camera, horizon, terrain shape, paths, lamps and buildings. Use strength about 0.55–0.65, so the layout holds and the planting and ground change.

Shared style, appended to every prompt:
> photoreal game screenshot, Unreal-quality real-time render, late-afternoon golden hour, eye-level 1.7 m first-person view, Tokyo city park in 2050 after an evacuation, lightly neglected but intact, muted natural olive greens (never lime), soft volumetric haze, distant Tokyo skyline. No people, no text, no UI.

Negative, for every prompt:
> lime green, neon grass, plastic look, stripes, repeating rows of plants, cartoon, fisheye, people, text, watermark, HUD
